Wine Chemistry HTML Package

Files:
- wine_chemistry_web.html: responsive compound tables organized by winemaking stage.
- wine_compound_count_web.html: long-form article with tables, figure, table of contents, and linked references.
- wine_compound_count_media/: image assets used by the long-form article.

Keep wine_compound_count_web.html and wine_compound_count_media/ in the same folder structure when publishing.
Both HTML files contain their CSS internally and can be opened directly in a browser.
